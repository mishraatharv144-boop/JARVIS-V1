# JARVIS V1

Phone-first Android assistant prototype based on the supplied JARVIS V1 specification.

Current V1 prototype:
- Android Kotlin + Jetpack Compose
- Microphone permission
- Hindi speech recognition
- Text-to-speech
- Basic local responses
- No hard-coded API key
- INTERNET and RECORD_AUDIO permissions only

Important: this is a buildable starter/prototype, not a complete cloud AI assistant. The supplied specification explicitly requires an AI provider/API for intelligent responses. Configure an AI provider before treating it as a full AI assistant.
